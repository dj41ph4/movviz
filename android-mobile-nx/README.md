# Movviz NX Mobile

Client Android tactile indépendant de Movviz Mobile et de Movviz NX TV.

- Identifiant : `com.movviz.nx.mobile`
- Mise à jour : `Movviz-NX-Mobile-client.apk`
- Signature : même clé retail Movviz que les autres APK
- Cibles : téléphone, tablette et appareils pliables Android

Le projet conserve le client mobile comme socle fonctionnel et possède ses propres
préférences, session et cache grâce à son `applicationId` distinct.
